# 手动测试清单

每次部署前逐项验证。在浏览器中打开页面，按顺序执行。

## 步骤 1：输入

- [ ] 粘贴 3-5 条中英文混合标题，点击「解析标题」
- [ ] 上传 .txt 文件，点击「解析标题」
- [ ] 上传 .xlsx 文件（含标题列），点击「解析标题」
- [ ] 上传 .docx 文件，点击「解析标题」
- [ ] 切换到「基础解析」，粘贴标题，验证正常
- [ ] 点击「高级设置」，填入 API 配置，保存后验证按钮高亮
- [ ] 使用 Ctrl+Enter 触发解析

## 步骤 2：确认

- [ ] 确认标题列表正确显示在可编辑表格中
- [ ] 双击单元格编辑标题
- [ ] 点击 ✕ 删除一行
- [ ] 点击「+ 添加一行」新增
- [ ] 点击「← 返回修改」回到步骤 1
- [ ] 点击步骤条中已完成的步骤可回退

## 步骤 3：结果

- [ ] 点击「批量查询 DOI」，进度条正常显示
- [ ] 查询中点击「取消查询」，已完成的保留
- [ ] 结果页面统计卡片数字正确（总计=高+低+未找到）
- [ ] 点击统计卡片可筛选表格
- [ ] 筛选低置信度或未找到时，出现「全部重试」按钮
- [ ] 点击单条 ↻ 重试，行显示转圈动画
- [ ] 点击「全部重试」，逐行显示转圈
- [ ] 重试后置信度 ≥90% 自动移入高置信度
- [ ] 复制全部 DOI 正常
- [ ] 下载 Excel 正常
- [ ] 右侧 「?」 使用说明正常弹出和关闭

## 边界测试

- [ ] 空输入 → 提示错误
- [ ] 超长标题（>600字符）→ 被过滤
- [ ] 输入纯中文段首标签（"代表性论文1"）→ 被过滤
- [ ] 论文标题含"第一作者"后缀 → 后缀被剥离
- [ ] 论文标题含"论文成果："前缀 → 前缀被剥离
- [ ] 已干净的标题行 → 智能检测跳过 LLM
- [ ] 预印本 DOI → 优先取正式版
- [ ] 英文停用词 a/an/the → 忽略后匹配
- [ ] 移动端（手机浏览器）查看三个步骤
